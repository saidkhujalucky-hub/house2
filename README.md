# HOUSE2 — Modern Villa Residence

Interaktiv, batafsil ishlangan ikki qavatli villaning **3D tashqi ko‘rinishi**.

### Onlayn demo

GitHub Pages yoqilgandan keyin: https://saidkhujalucky-hub.github.io/house2/

### Imkoniyatlar

- Zamonaviy ikki qavatli villaning 3D tashqi ko‘rinishi
- Hovli, basseyn va atrof-muhit detalizatsiyasi
- Sichqoncha/touch orqali kamerani boshqarish
- 360° avtomatik tur
- Kameraning tayyor rakurslari: umumiy, kirish, basseyn, balkon, yuqoridan
- Kun, shom va tun rejimlari
- Telefon va kompyuter ekranlariga moslashgan interfeys

### Ishga tushirish

Loyiha bitta `index.html` faylida yig‘ilgan — build, `npm install` yoki server talab qilinmaydi. Lokal test uchun `index.html` ni zamonaviy brauzerda oching.

**GitHub Pages:** Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save.

### Chegaralar

Bu **real estate marketplace'ning 3D demo qismi**, to‘liq marketplace emas. Login, NestJS backend, Prisma/PostgreSQL, e’lonlar CRUD va admin panel bu repozitoriyda tayyor emas. Uy konseptual model, real obyektning o‘lchovlari asosida yaratilmagan.
